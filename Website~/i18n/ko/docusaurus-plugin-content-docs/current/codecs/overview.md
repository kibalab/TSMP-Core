# 코덱

코덱은 TSMP 데이터가 픽셀로 표현되는 방식을 결정합니다. Luma4로 송신부터 수신까지 확인한 뒤, 측정 결과 더 높은 payload 밀도가 필요할 때 다른 코덱을 검토하세요.

## 코덱 선택

| 코덱 | 권장 용도 | 현재 근거와 제한 |
| --- | --- | --- |
| Luma4 | 기본 시작점과 문제 진단 기준입니다. | 다른 코덱이 payload를 기록해도 모든 프레임의 header 처리에 필요합니다. Core와 함께 설치하는 별도 패키지입니다. |
| Color256 | 더 높은 payload 밀도가 필요할 때 조건부로 사용합니다. | 저장된 OBS 테스트의 검은 화면을 제외한 관측 1,216/1,216개를 보존했습니다. 실제 경로의 색 변환, 압축, 유효 갱신률을 검증해야 합니다. |
| RGB16 | 검증한 프리셋과 수신 복구를 함께 사용할 때 조건부로 선택합니다. | 현재 개발 브랜치의 Refine은 저장된 OBS의 검은 화면을 제외한 1,212/1,212개를 복원했습니다. 이전 수신기의 실패 9개도 포함하며, 다른 설정에서는 payload가 거부될 수 있습니다. |
| RGB20 | Payload의 바이트 보존을 검증한 색상 보존 경로에서 사용합니다. | 일반 OBS H.264/NV12에는 권장하지 않습니다. PNG/RGB 무손실 대조군은 통과했지만 저장된 OBS의 검은 화면을 제외한 관측은 0/1,213개가 통과했습니다. 높은 비트레이트나 Refine만으로 호환성이 확인되지는 않았습니다. |

이는 반복·정지 프레임을 포함한 유한한 녹화 파일의 관측 결과입니다. 고유 갱신률이나 실제 VRChat, VRCDN, RTMP/RTSP, HLS 재생의 보장 수치가 아닙니다. 컨테이너만 바꾼 테스트는 원본 프레임을 보존했으며 압축 손상을 복구하지 않았습니다. CRF28은 측정한 payload 대부분에 여전히 부적합합니다. 현재 검증 진입점과 별도 실제 환경 검증 항목은 [개발자 테스트](../developer/testing.md)를 확인하세요.

RGB16 복구와 최근 성능 수정은 개발 브랜치의 변경입니다. 같은 기본 버전 번호의 배포 패키지에 포함됐다고 가정하지 말고, 설정 평가 시 테스트한 정확한 리비전을 기록하세요.

## Header와 payload 코덱 설치

일반 Unity와 VRChat 모두 **TSMP Core**와 **TSMP Codec Luma4**를 설치합니다. 컬러 payload를 사용하려면 해당 코덱 패키지도 설치합니다. Payload 코덱을 식별하는 header를 읽는 데는 Luma4가 계속 필요합니다.

현재 개발 브랜치의 컬러 코덱에는 Luma4가 VPM 의존성으로 선언돼 있습니다. 이 수정 이전의 배포 버전에서는 누락될 수 있으므로 세 패키지가 모두 설치됐는지 확인하세요. 로컬/디스크 또는 Git UPM 설치에서는 프로젝트 의존성에 Core, Luma4, 선택한 코덱을 직접 지정하세요. 숫자형 패키지 의존성만으로 GitHub 저장소를 찾지는 않습니다. [설치 안내](../getting-started/installation.md)를 참고하세요.

1. `TSMPSetup`을 열고 코덱 목록을 새로 고칩니다.
2. Codec 탭에서 payload 코덱을 선택합니다.
3. 수동으로 설정을 갱신할 때는 `Apply Setup`을 클릭합니다.
4. 송신기와 수신기의 코덱 옵션이 호환되고 header용 Luma4가 계속 할당돼 있는지 확인합니다.

## 프레임 디코딩이 실패할 때

고급 설정을 바꾸기 전에 다음을 확인하세요.

- 인코딩 영역이 확대·축소되거나 필터링되지 않습니다.
- OBS 또는 카메라 출력에 색 보정이 적용되지 않습니다.
- 수신기가 올바른 입력 텍스처를 읽고 있습니다.
- Header 영역을 포함한 TSMP 프레임 전체가 보입니다.
- Header와 payload CRC 진단값으로 실패 단계를 확인합니다.

Codec 탭에 Luma4가 보이지 않으면 씬 바인딩을 디버깅하기 전에 해당 패키지를 설치하거나 새로 고치세요. Refine은 제한된 재시도 안에서 일부 손상된 심볼을 복구할 수 있지만, 사라진 프레임이나 전송 과정에서 구별할 수 없게 된 색을 되살릴 수는 없습니다.
