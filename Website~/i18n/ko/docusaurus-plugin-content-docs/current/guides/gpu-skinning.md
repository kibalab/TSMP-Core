---
title: 휴머노이드 수신 모델의 GPU 스키닝
---

월드에서 **공연자의 모습을 그리는 용도**라면, 송신 측의 `TSMPNetworkHumanoidPoseSync`는 그대로 사용하고 수신 측에서는 [셰이더 채널](./shader-receive.md)의 값으로 메시를 변형할 수 있습니다. 씬의 본 Transform, 콜라이더, 본에 붙은 소품은 움직이지 않습니다. 다른 컴포넌트가 본 위치를 사용한다면 기존 CPU 수신도 유지하세요.

## 수신 모델 베이크하기

1. 수신 디코더에서 **Shader Channel**을 켭니다. 먼저 디코더와 코덱에서 정상 프레임을 받고 있어야 합니다.
2. Edit Mode에서 수신 모델의 유효한 Humanoid Animator를 기본 자세로 놓고 자식 SkinnedMeshRenderer를 선택하세요. 원본 모델은 **Read/Write Enabled**이고 본 Transform에 접근할 수 있어야 하며, 정점당 가중치는 최대 4개입니다. 가중치가 있는 본은 Hips 또는 그 하위에 있어야 합니다. Animator 및 그 상위, Animator와 Hips 사이의 Transform은 양수 균일 스케일을 사용하세요.
3. **TSMP → Bake Humanoid GPU Skin**을 엽니다. 디코더 인스펙터의 **Bake Humanoid GPU Skin**으로 열면 해당 디코더가 미리 선택됩니다. 수신 Animator와 Source Renderer를 지정하세요. 송신 포즈 컴포넌트와 디코더를 지정하면 Network ID와 채널을 읽습니다. 송신자가 다른 프로젝트에 있는 경우처럼 참조할 수 없는 쪽은 비워 두고 값을 직접 입력하세요. 이 값은 에셋에 저장되므로 ID나 채널이 바뀌면 다시 베이크하세요. **Motion Margin**은 메시의 각 방향으로 추가할 이동 여유 범위입니다(Animator 로컬 단위). World 루트 모션이면 수신 모델을 무대 근처에 두세요. Unity는 셰이더가 옮긴 정점이 아닌 고정 범위로 컬링합니다.
4. **Bake GPU Skin**을 눌러 Assets 안의 새 에셋으로 저장하고 씬을 저장합니다. **Last Bake**에서 생성된 GPU 렌더러와 베이크 메시를 확인할 수 있습니다. 전체를 GPU로 그리면 원래 렌더러는 꺼집니다. 혼합 베이크에서는 남겨둔 삼각형만 원래 렌더러가 그립니다. 임포트한 모델 에셋은 변경되지 않습니다. 여러 메시라면 각각 베이크하세요. 생성된 오브젝트의 로컬 Transform은 변경하지 말고 정적 배칭도 켜지 마세요.
5. 송신 애니메이션을 재생합니다. Hips의 Local·World 모션을 모두 지원합니다. 수신용 포즈 컴포넌트는 필요하지 않습니다. 다른 용도가 없는 기존 CPU 수신기는 끄거나 수신 모드를 **None**으로 설정하세요.

생성된 에셋에 메시, 리그 정보, 팔레트, 머티리얼이 함께 저장됩니다. 기본 Built-in 불투명 셰이더는 원본의 알베도 텍스처, 타일링·오프셋, 틴트만 가져옵니다. 원래 셰이더 전체가 변환되지는 않습니다. 본 계층·가중치·기본 자세를 바꿨다면 다시 베이크하세요. 베이크 직후 Edit → Undo로 씬 오브젝트와 원래 렌더러의 할당을 복원할 수 있습니다. 생성한 에셋은 Project에 남습니다.

## 어떤 움직임이 적용되나요?

GPU 패스 두 개가 현재 v4 `humanoid.pose` 값을 풀고 본별 행렬을 만듭니다. 머티리얼은 이 행렬로 정점 위치·노멀·탄젠트를 변형합니다. 본마다 Udon으로 Transform을 쓰거나 스키닝 결과를 readback하지 않습니다. 디코더 자체의 프레임 검증과 readback은 그대로이며, 베이크된 메시마다 렌더 프레임당 팔레트 두 개를 갱신합니다. 이 구조만으로 특정 성능 향상 수치를 보장하지는 않습니다.

선택된 휴머노이드 본의 회전은 보간 없이 적용합니다. 미선택 본과 보조 본은 베이크된 로컬 자세를 유지합니다. 포즈 필드가 생략되면 마지막 포즈를 유지하고, 채널이 없거나 포즈 패킷 형식이 잘못되면 본은 기본 자세로 돌아갑니다. 표정은 별도로 처리합니다. 이 셰이더는 VRChat 플레이어 풀, 물리 시뮬레이션, CPU 수신 보간을 처리하지 않습니다.

## 얼굴 표정 송수신

1. 송신 얼굴 렌더러의 `TSMPNetworkBlendShapesSync`에서 Blink, MouthOpen 등 보낼 키만 선택합니다.
2. **Bake Humanoid GPU Skin**의 **BlendShape Sender**에 해당 컴포넌트를 지정합니다. 송신자가 다른 프로젝트에 있다면 같은 메시와 선택 목록을 가진 송신 프리팹을 지정하고, **BlendShape Network ID**가 실제 송신 ID와 같은지 확인하세요. 포즈 ID와 표정 ID는 달라도 되지만 같은 디코더 채널로 수신해야 합니다.
3. 수신 얼굴 메시를 베이크합니다. 선택한 키의 **이름**이 모두 일치해야 하며, 키 순서와 메시 정점 구성은 달라도 됩니다. 송신 메시의 키 인덱스, 선택 목록, ID 또는 수신 표정 모양이 바뀌면 다시 베이크하세요. 표정 송신자를 비워 두면 추가 패스 없이 포즈만 처리합니다.

가중치는 0~100 정수이며 보간 없이 적용됩니다. 셰이더는 본 스키닝 전에 수신 메시의 표정 프레임을 적용합니다. 양수 가중치가 증가하는 여러 중간 프레임도 지원합니다. 표정 필드 전체가 생략되면 마지막 값을 유지하고, 새 표정 패킷에서 빠진 키는 0이 됩니다. 필드를 읽을 수 없거나 형식이 잘못되면 표정만 중립으로 돌아갑니다. 표정이 있는 베이크마다 가중치 텍스처 하나를 추가로 갱신하고, 각 정점은 자신에게 영향을 주는 데이터만 읽습니다.

혼합 베이크에서는 생성된 MeshRenderer에만 GPU 표정이 적용됩니다. 원래 SkinnedMeshRenderer에 남긴 삼각형에도 표정이 필요하면 기존 표정 수신기나 애니메이션을 유지하세요. 기존 CPU 표정 수신기는 이름이 아니라 **인덱스**로 매칭합니다.

## 송신에서 본 제외하기

송신 측 `TSMPNetworkHumanoidPoseSync`의 **Excluded Send Bone Roots**에 Hips 아래의 본을 넣으세요. 지정한 본과 자식 본은 송신하지 않습니다. 예를 들어 Head의 움직임은 보내고 머리카락만 제외하려면 Head가 아니라 HairRoot를 선택하세요. 물리나 GPU 스키닝 없이도 쓸 수 있습니다. 수신 측에는 같은 목록을 설정할 필요가 없습니다. 받은 본을 적용할지는 기존 리그 맵이 결정합니다. 매핑된 회전 하나를 제외하면 포즈당 6바이트가 줄고, 매핑되지 않은 보조 본은 원래 전송되지 않습니다.

**렌더링은 별도 설정입니다.** 수신 메시 일부를 애니메이션·제약·물리로 움직이려면 베이크 창의 **Keep on Skinned Renderer**에 해당 **수신 리그의 본**을 넣으세요. 그 하위 본의 가중치를 조금이라도 받는 삼각형은 원래 렌더러에 남고, 가중치·머티리얼 슬롯·BlendShape 프레임도 유지됩니다. 비워 두면 전체를 GPU로 그립니다. 전체가 원래 렌더러에 남을 장식 메시는 베이크할 필요가 없습니다.

로컬 본이 송신 자세를 따라가야 한다면 송신 ID에 바인딩된 **Discrete** CPU 수신기로 실제 상위 본과 경계 정점에 영향을 주는 비제외 본을 움직이세요. CPU와 셰이더의 갱신 시점은 다를 수 있습니다. 메시 분할을 바꾸려면 원본 메시를 복원하고 생성 렌더러를 삭제한 뒤 다시 베이크하세요. 송신 목록만 바꿀 때는 베이크할 필요가 없습니다. 런타임에 본의 부모를 바꿨다면 `InvalidateReceiveRig()`를 호출하세요.

메시를 분할하면 각 렌더러에는 삼각형이 남은 머티리얼 슬롯만 원래 순서대로 유지됩니다. 원본의 마지막 서브메시에 겹쳐 그리던 추가 머티리얼은 그 삼각형이 남은 쪽에만 적용됩니다. 슬롯 번호로 머티리얼을 바꾸는 애니메이션이나 스크립트는 베이크 후 번호를 확인하세요. 다시 베이크할 때는 원본 메시와 머티리얼 목록을 모두 복원해야 합니다. 기존 베이크는 자동으로 바뀌지 않습니다.

## 커스텀 머티리얼

머티리얼의 2D 프로퍼티 `_TSMPSkinPalette`에 생성된 스킨 팔레트를 지정하세요. 배칭을 끄고 그림자를 포함해 기하를 그리는 모든 패스에 변형을 적용합니다. **베이크한 복사본**의 UV3·UV4에 각각 본 인덱스와 가중치가 들어 있습니다. 클립 공간 변환 전에 다음 함수를 호출하세요.

표정도 적용하려면 생성된 머티리얼에서 `_TSMPShapeWeights`, `_TSMPShapeDeltas` 텍스처를 가져오고 머티리얼의 `TSMP_BLEND_SHAPES` 키워드를 켜세요. UV2.xy는 유지되며 UV2.zw는 정점별 표정 데이터의 위치를 나타냅니다.

```hlsl
#pragma target 3.5
#pragma shader_feature_local _ TSMP_BLEND_SHAPES
#include "Packages/com.kibalab.tsmp.core/Shaders/TSMPSkinning.cginc"

void vert(inout appdata_full v)
{
    float3 p = v.vertex.xyz;
    TSMPApplyBlendShapes(p, v.normal, v.tangent, v.texcoord1.zw);
    TSMPSkinVertex(p, v.normal, v.tangent, v.texcoord2, v.texcoord3);
    v.vertex.xyz = p;
}
```
