# 用語集

TSMP という用語がインスペクター、デバッグ キャンバス、またはログに表示される場合は、このページを使用します。

| 学期 | 意味 |
| --- | --- |
| フレーム | 1 つの完全な TSMP テクスチャ更新。これにはヘッダーとオプションのペイロードが含まれます。 |
| ヘッダ | フレームの先頭にある固定の 56 バイトのメタデータ ブロック。 |
| ペイロード | ヘッダーの後のデータ本体。ネットワークメッセージが含まれています。 |
| コーデック | バイトをピクセルに変換し、ピクセルをバイトに戻すコンポーネント。 |
| Luma4 | サンプル プレハブで使用されるデフォルトの TSMP コーデック。 |
| ネットワークID | 一致する `TSMPNetworkBehaviour` にメッセージをルーティングするために使用される ID。 |
| バインディング | ネットワーク ID とフィールド ハッシュをコンポーネント フィールドにマッピングする生成されたセットアップ データ。 |
| 変数の状態 | 1 つ以上の同期されたフィールド値を含むペイロード メッセージ。 |
| TSMP RPC | テクスチャ ストリームを通じてメソッドのようなイベントを送出するペイロード メッセージ。 |
| フレームインデックス | 送信者の増加するフレーム番号。重複や紛失の検出に役立ちます。 |
| CRC | 破損したヘッダーを拒否するために使用されるチェックサム。 |
| ペイロード容量 | 現在のテクスチャとコーデックが伝送できるペイロード バイト数。 |
| 受信補間 | 受信した値を適用する方法を決定するコンポーネントごとの設定。 |
| 輸送 | VRChat カメラ出力、Spout、または OBS など、エンコードされたテクスチャを運ぶパス。 |

## 一般的なデバッグ フレーズ

| フレーズ | 通常、意味するのは |
| --- | --- |
| `Payload buffer is full` | 選択した同期データが現在のフレームに収まりません。 |
| `Header CRC mismatch` | トランスポートがヘッダー ピクセルを変更したか、受信機が間違った領域を読み取っています。 |
| `payload=0` | エンコーダは実行中ですが、選択されたデータが書き込まれませんでした。 |
| RX の `msg=0` | デコーダはフレームを検出しましたが、使用可能なネットワーク メッセージが見つかりませんでした。 |
| `ReceiveInterpolation=None` | コンポーネントは受信した値を意図的に無視します。 |
