---
title: ヒューマノイド受信モデルの GPU スキニング
---

ワールド内に**演者の姿を描画する**ための方法です。送信側は通常の `TSMPNetworkHumanoidPoseSync` を使い、受信側は[シェーダーチャンネル](./shader-receive.md)からベイク済みのメッシュを変形します。シーンのボーン Transform やコライダー、ボーンに付けた小物は動きません。他のコンポーネントでボーン位置が必要なら CPU 受信も残してください。

## 受信モデルをベイクする

1. 受信側デコーダーの **Shader Channel** を有効にし、チャンネル番号（0～3）と**送信側**のヒューマノイドポーズの Network ID を確認します。先にデコーダーとコーデックで正常なフレームを受信できる状態にしてください。
2. Edit Mode で受信モデルの有効な Humanoid Animator を基準姿勢にし、その子の SkinnedMeshRenderer を選びます。モデルは **Read/Write Enabled** でボーン Transform が公開され、ウェイトは頂点あたり 4 個以下である必要があります。ウェイトを持つボーンは Hips またはその子孫に限ります。Animator とその祖先、Animator と Hips の間の Transform には正の均一スケールを使用してください。
3. **TSMP → Bake Humanoid GPU Skin** で Animator とレンダラーを選び、送信側の ID とデコーダーのチャンネル番号を入力します。**Motion Margin** はメッシュの各方向へ加える移動範囲（Animator ローカル単位）です。World ルートモーションでは受信モデルをステージ付近に配置してください。カリングには変形後の頂点ではなく、この固定範囲が使われます。
4. **Bake GPU Skin** を押して Assets 内の新規アセットに保存し、シーンを保存します。Animator 配下に MeshRenderer が作られ、元のレンダラーは無効になります。元のメッシュとマテリアルは変更しません。複数メッシュの場合はそれぞれベイクしてください。生成オブジェクトのローカル Transform は変更せず、静的バッチングの対象にも含めないでください。
5. 送信側のアニメーションを再生します。Hips の Local・World モーションに対応します。受信用ポーズコンポーネントは不要です。他の用途がなければ CPU 側の受信を無効にするか、受信モードを **None** にしてください。

生成されるアセットにはメッシュ、リグ情報、パレット、マテリアルが入っています。標準の Built-in 用不透明シェーダーはアルベドテクスチャ、タイリング・オフセット、色を引き継ぎますが、元のシェーダー全体は変換しません。ボーン階層・ウェイト・基準姿勢を変更した場合は再ベイクしてください。元に戻すには生成オブジェクトを削除して元のレンダラーを有効にします。

## 反映される動き

2 つの GPU パスが現在の v4 `humanoid.pose` を読み、ボーン行列を生成します。マテリアルはこの行列で頂点位置・法線・接線を変形します。ボーンごとの Udon Transform 書き込みやスキニング結果の readback はありません。デコーダー自体の検証と readback は従来どおりです。ベイクした各メッシュにつき、描画フレームごとに 2 枚のパレットを更新します。特定のフレーム時間の短縮を保証するものではありません。

選択されたヒューマノイドボーンの回転は補間せずに適用します。未選択のボーンと補助ボーンはベイク時のローカル姿勢を保ち、親に追従します。SendOnChange でフィールド全体が省略されても直前の値を保ちます。チャンネルやフィールドがない場合や未対応の形式では基準姿勢を表示します。VRChat プレイヤープールの別形式のパケット、揺れものの物理演算、BlendShape、CPU 受信補間には対応していません。

## カスタムマテリアル

マテリアルの 2D プロパティ `_TSMPSkinPalette` に生成済みのスキンパレットを指定し、バッチングを無効にします。影を含め、メッシュを描画するすべてのパスに変形を適用してください。**ベイクしたコピー**の UV3 と UV4 にはそれぞれボーンインデックスとウェイトが入っています。クリップ空間へ変換する前に次の関数を呼びます。

```hlsl
#pragma target 3.5
#include "Packages/com.kibalab.tsmp.core/Shaders/TSMPSkinning.cginc"

void vert(inout appdata_full v)
{
    float3 p = v.vertex.xyz;
    TSMPSkinVertex(p, v.normal, v.tangent, v.texcoord2, v.texcoord3);
    v.vertex.xyz = p;
}
```
