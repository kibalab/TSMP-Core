# コーデック

コーデックは TSMP データをピクセルで表現する方法を決めます。Luma4 で送信から受信までを確認し、測定でさらに高い payload 密度が必要になった場合に別のコーデックを検討してください。

## コーデックの選択

| コーデック | 推奨用途 | 現在の根拠と制限 |
| --- | --- | --- |
| Luma4 | 最初の設定とトラブルシューティングの基準です。 | 別のコーデックが payload を書く場合も、全フレームのヘッダー処理に必要です。Core と一緒にインストールする別パッケージです。 |
| Color256 | より高い payload 密度が必要な場合の条件付き候補です。 | 保存済み OBS テストでは黒画面を除く観測 1,216/1,216 件を保持しました。実際の経路で色変換、圧縮、有効な更新頻度を検証してください。 |
| RGB16 | 検証済みプリセットと受信側の復元を併用する場合の条件付き候補です。 | 現在の開発ブランチの Refine は、以前の受信側で失敗した 9 件を含む、黒画面以外の保存済み OBS 観測 1,212/1,212 件を復元しました。他の設定では payload が拒否される場合があります。 |
| RGB20 | Payload のバイト保持を検証した、色を保持する経路で使用します。 | 通常の OBS H.264/NV12 には推奨しません。PNG/RGB ロスレス対照群は通過しましたが、黒画面を除く保存済み OBS 観測の通過は 0/1,213 件でした。高ビットレートや Refine だけでは互換性が確認されていません。 |

これは反復・静止フレームを含む有限の録画ファイルの観測結果です。固有の更新頻度や、実際の VRChat、VRCDN、RTMP/RTSP、HLS 再生を保証する数値ではありません。コンテナーのみの変更では元のフレームが保持され、圧縮による破損は修復されませんでした。CRF28 は測定した payload の大半に依然として不向きです。現在の検証入口と別途必要な実環境検証は [開発者テスト](../developer/testing.md) を参照してください。

RGB16 の復元と最近の性能修正は開発ブランチの変更です。同じ基本バージョン番号の公開パッケージに含まれていると仮定せず、設定を評価した正確なリビジョンを記録してください。

## ヘッダーと payload のコーデックをインストール

通常の Unity と VRChat の両方で **TSMP Core** と **TSMP Codec Luma4** をインストールします。カラー payload を使用する場合は、そのコーデックパッケージもインストールします。Payload のコーデックを識別するヘッダーを読むため、Luma4 は引き続き必要です。

現在の開発ブランチでは、カラーコーデックの VPM 依存関係に Luma4 が宣言されています。この修正以前の公開版では欠けている場合があるため、3 つのパッケージがすべてインストールされていることを確認してください。ローカル/ディスクまたは Git による UPM インストールでは、プロジェクトの依存関係に Core、Luma4、選択したコーデックを直接指定してください。数値のパッケージ依存関係だけでは GitHub リポジトリは見つかりません。[インストール](../getting-started/installation.md) を参照してください。

1. `TSMPSetup` を開き、コーデック一覧を更新します。
2. Codec タブで payload のコーデックを選びます。
3. 手動で設定を更新する場合は `Apply Setup` をクリックします。
4. 送受信側のコーデックオプションに互換性があり、ヘッダー用の Luma4 が引き続き割り当てられていることを確認します。

## フレームのデコードに失敗する場合

詳細設定を変える前に、以下を確認してください。

- エンコード領域が拡大・縮小またはフィルタリングされていません。
- OBS またはカメラ出力に色補正が適用されていません。
- 受信側が正しい入力テクスチャを読んでいます。
- ヘッダー領域を含む TSMP フレーム全体が見えています。
- ヘッダーと payload の CRC 診断値で失敗した段階を確認します。

Codec タブに Luma4 が表示されない場合は、シーンのバインディングを調べる前にパッケージをインストールまたは更新してください。Refine は制限された再試行内で一部の破損したシンボルを復元できますが、失われたフレームや転送中に区別できなくなった色は復元できません。
